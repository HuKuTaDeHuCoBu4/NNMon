# Changelog

## [1.0.0] – 2026-07-15

### Добавлено
- Мониторинг пинга до роутера и двух внешних серверов в реальном времени.
- Мега-диагностика с анализом ICMP, DNS, HTTP, UDP, TCP/DPI, буферблоата и Wi-Fi.
- Звуковые уведомления о потерях и высоком пинге.
- Логирование сессий, статистика, автосохранение CSV.
- Консольный GUI с иконкой в системном трее.
- Обновлена мицелиевая связь.
- Подробные ASCII-схемы ключевых узлов комплекса.

### Исправлено
- Корректное определение медленных DNS-запросов в вердикте диагностики.
- Устранено ложное срабатывание буферблоата при сверхмалых задержках (абсолютный порог >30 мс, рост >100%).
- Стабильность интерфейса при длительных сессиях.

### Изменено
- Порог уверенности для буферблоата повышен.
- Категории в сводке диагностики сортируются по алфавиту.
- Плавная смена экранов скрытого раздела без мерцания.
